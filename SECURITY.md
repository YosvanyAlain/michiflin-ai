# Security Policy

## Reporting a vulnerability

Please do not publish credentials, contact addresses, account identifiers, or exploitable details in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled. If it is not enabled, contact the repository owner through a private channel already known to you.

Include the affected version/commit, impact, and steps to reproduce. Do not test against third-party systems or other users.

## Scope

This project handles private Delta Chat account state, third-party AI/API credentials, user-supplied URLs, and downloaded files. Treat backups and CI logs as sensitive even when the backup is encrypted.
